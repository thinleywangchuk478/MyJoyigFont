# ThinWangT_Joyig

ThinWangT_Joyig is a custom cursive script font inspired by traditional Bhutanese Joyig calligraphy.

## Description
This font brings the informal, flowing handwritten Joyig style into a modern digital `.ttf` format. It features custom glyph layouts optimized for natural writing fluidity on the web and in digital documents.

## Repository Structure
* `/fonts/ttf/ThinWangT_Joyig.ttf` - Main production font file.
* `OFL.txt` - Licensing information.
* `AUTHORS.txt` - Project contributors.
